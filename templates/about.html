Acerca del Proyecto

Objetivo

Implementar un sistema de análisis inteligente basado en datos abiertos para identificar patrones que afectan la sostenibilidad del emprendimiento en Cundinamarca.

Enfoque Metodológico

Se aplican técnicas de minería de datos para extraer, transformar y analizar información poblacional, identificando correlaciones y tendencias significativas para la toma de decisiones territoriales.

Fuentes de Datos

  • Datos abiertos de caracterización poblacional
  • Estadísticas demográficas oficiales
  • Indicadores económicos por localidad

Tecnologías Utilizadas

  • Python con Flask para el backend
  • Plotly para visualización interactiva
  • Pandas para procesamiento de datos
  • Bootstrap para interfaz responsive

Proyecto académico enfocado en minería de datos aplicada a políticas de emprendimiento.
